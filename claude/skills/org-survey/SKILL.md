# org 横断リポジトリ調査

## 手順

1. `gh repo list <org> --limit <N> --json name` で対象の全量を確定し、件数を報告する。「など」で対象を濁さない
2. ghq 配下の既存クローンを一括更新する。未クローンは `ghq get`。dirty なリポジトリは pull せずスキップし、スキップした事実を結果に含める
3. 横断 grep で候補リポジトリを絞る
4. 候補の詳細調査はリポジトリ単位で分割する。並列実行の手段があれば1単位に独立した複数リポジトリを割り当てて委譲する
5. 集計は「リポジトリ × 対象項目 × 環境(prd/stg)」の表にする。推定で埋めた項目には「要確認」を付ける
6. 認証が必要な検証はコマンドを提示してユーザーに実行してもらい裏取りする

## 落とし穴

- zsh の MULTIOS でバックグラウンドの git fetch がハングする。一括更新は `bash -c` で実行する
- 名称の表記揺れ(ハイフン/アンダースコア・大文字小文字)は両形式で grep する
